# MUSE interactive examples

Anonymous supplementary material for MUSE.

Explore 14 curated examples of 3D scene editing. Choose an example, send its
preset instruction, compare the result, and replay each edit.

These are prepared scene sequences, not a live generation service.

## Local preview

```bash
python3 -m http.server 8018
```

## GitHub Pages

In Settings → Pages, choose Deploy from a branch, main, and / (root).

Website: https://anonymousauthor608.github.io/muse_demo/

All scripts, images, and 3D assets are served locally. Third-party library licenses
are included under static/vendor.
